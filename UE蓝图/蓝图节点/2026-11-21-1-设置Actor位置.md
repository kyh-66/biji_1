# 设置 Actor 位置（Set Actor Location）

把整个 Actor（准确说是它的根组件）挪到指定的世界坐标，是蓝图里最常用的位移节点。

## 干什么用的

直接改变 Actor 的位置，不走物理、不走插值，就是"设成这个坐标"。
移动方向要么是你算出来的，要么来自另一个 Actor 的位置。

## 输入 / 输出

| 引脚 | 类型 | 说明 |
|---|---|---|
| Target | Actor | 要移动的 Actor，通常是 Self 或某个引用 |
| New Location | Vector | 目标位置，**世界坐标** |
| Sweep | Boolean | 是否做扫描碰撞：沿路径扫一遍，撞到东西就停在接触点 |
| Teleport | Boolean | 勾上视为瞬移，物理系统不当成"移动"处理 |
| Sweep Hit Result | Hit Result | Sweep 为 true 时输出，记录撞到了谁、撞在哪个点 |
| Return Value | Boolean | Sweep 为 true 时表示有没有到达目标点；Sweep 为 false 时恒为 true |

想改相对位置用 **Set Actor Relative Location**，别拿这个节点硬算。

## 典型场景

- **复活 / 传送 / 关卡内跳点**：Sweep 关、Teleport 开。瞬移就是瞬移，别让碰撞把角色卡在半路。
- **开门、升降台、浮空平台**：每帧算一个插值后的位置喂进来，Sweep 看情况开，Teleport 关。
- **投射物飞行**：用 Sweep 开、Teleport 关，让它撞墙就停；但射速高的子弹更推荐用 Projectile Movement 组件或射线检测再设位置。
- **把东西吸附到地面**：从上方往下做一次 Line Trace，拿到命中点再设置位置，比盲设坐标稳。

## 坑

- **Sweep 只保证这一段的碰撞**。它检查的是起点到终点这条线段，能拦住薄墙；但只要 Teleport 开着或者你用 Add Actor World Offset 且没开 Sweep，穿墙照穿。
- **物理模拟的 Actor 别直接设位置**。刚体有自己的速度，你设完下一帧物理又把它拽回去；要推它得用 Add Impulse / Set Physics Linear Velocity，或者 Teleport 开=true 强制定位（这会清掉当前速度）。
- **附着在别的组件上会打架**。Attach 到骨骼/父组件上的 Actor，每帧会被父级拉回原位，先 Detach 再设位置。
- **返回值别拿来判断"到没到"**。Sweep=false 时它永远是 true，拿它做逻辑判断会静默出错。
- **逐帧裸设位置会抖**。没有插值和速度，视觉上是硬跳；要平滑就自己插值，或者干脆用 Move Component To。
- **根组件被替换过**的话，设置的是新根组件的位置，老引用可能已经对不上了。
